# Manuscript reproducibility

This directory is reserved for simulation code, benchmarking comparisons, real-data analyses, and figure-generation notebooks used for the scCST manuscript.

These files are not required to run scCST on a new dataset. For normal usage, see `src/sccst/`, `scripts/`, and `examples/`.

Benchmarking folders are intentionally included as placeholders so notebooks and scripts can be added later.
