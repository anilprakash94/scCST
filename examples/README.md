# Examples

This directory contains example notebooks for running scCST and analyzing its outputs.

- `kang_ifnb_run_sccst.ipynb`: original Kang IFN-beta PBMC scCST run notebook.
- `kang_ifnb_downstream_analysis.ipynb`: downstream analysis of scCST gene scores and cell divergence scores.

The notebooks retain the original development paths and may need path edits before running on another machine. For reusable code, use the Python package under `src/sccst/`.
